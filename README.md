# عينك المساعدة — لوحة المساعد البصري

تطبيق Next.js وTypeScript عربي RTL مع تبديل إلى الإنجليزية. تتيح اللوحة تشغيل كاميرا الجهاز بإذن المستخدم، والتقاط صورة عند الطلب، ووصف المشهد أو فحص احتمال ظهور عائق عبر نموذج رؤية رسمي. تتضمن قراءة النتائج صوتيًا، وإعدادات سرعة القراءة ومستوى صوتها، وحالة النظام وسجلًا محليًا مختصرًا. تصميم اللوحة لا يوحي بأن نظارة فعلية متصلة؛ إقران النظارة يحتاج إلى العتاد وبرنامج التشغيل أو واجهة الشركة المصنّعة.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث.

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

افتح `http://localhost:3000`. يعمل الموقع دون مفتاح API، لكن تحليل الصور يتطلب مفتاح خدمة الرؤية الخادمي:

```dotenv
OPENAI_API_KEY=your-server-side-key
AI_VISION_MODEL=gpt-4o-mini
```

أعد تشغيل الخادم بعد تعديل `.env.local`. لا تستخدم بادئة `NEXT_PUBLIC_` للمفتاح ولا تضعه في الشيفرة أو المستودع. عند توفر المفتاح، يرسل الخادم صورة واحدة للخدمة الرسمية عند طلب المستخدم، ولا يوجد تحليل تلقائي بالخلفية. راجع شروط الخدمة وسياسة الاحتفاظ ببيانات الصور لدى المزود قبل تفعيل الميزة.

## الكاميرا والخصوصية

زر بدء المساعدة يطلب إذن الكاميرا الخلفية على الهاتف أو الكاميرا المتاحة على الكمبيوتر. يُعرض الفيديو محليًا؛ لا يُرسل أي إطار للخادم إلا عند طلب وصف المشهد أو فحص العوائق. يتوقف تيار الكاميرا عند إيقاف المساعدة. يلزم `localhost` للتطوير المحلي أو HTTPS في النشر لاستخدام كاميرا المتصفح. يمكن اختيار صورة محفوظة بدلًا من تشغيل الكاميرا.

إن لم تُجهّز خدمة تحليل الصور، تعرض اللوحة أن التحليل غير متاح بدلًا من اختلاق وصف. Web Speech API اختياري ويتطلب أصواتًا يدعمها المتصفح للغة المحددة.

## فحص المشروع وبناؤه

```powershell
npm run typecheck
npm run build
npm run start
```

## نشر Vercel

1. استورد مستودع المشروع في Vercel كمشروع Next.js.
2. أضف `OPENAI_API_KEY` و`AI_VISION_MODEL` إلى متغيرات البيئة الخادمية للبيئات المطلوبة، دون تضمين المفتاح في الشيفرة.
3. انشر التطبيق على HTTPS. فعّل تحديد معدل الطلبات على `/api/analyze` قبل فتح واجهة التحليل للعامة للحد من إساءة الاستخدام وتكاليف المزود.

تحليل الصورة وأي تنبيه احتمالي وسيلة مساندة وصفية لإطار واحد، وليس نظام ملاحة، ولا يضمن اكتشاف العوائق أو منع الحوادث. استخدم وسائل السلامة المعتادة، بما فيها العصا البيضاء عند الحاجة.
